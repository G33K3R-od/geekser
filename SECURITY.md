# Security policy

Geekser is **pre-alpha** and does not currently provide a supported browser release.

## Reporting vulnerabilities

Please **do not disclose exploitable vulnerabilities in public GitHub Issues**. Contact the repository maintainer through GitHub's private vulnerability reporting feature **if enabled**, or request a private contact channel without posting exploit details publicly. A dedicated security address has not yet been established.

## Security priorities

- Preserve upstream Firefox/Gecko security protections.
- Track and integrate upstream security fixes promptly once a fork exists.
- Review code that handles URLs, profiles, downloads, credentials, permissions and web content.
- Avoid adding telemetry or sending browsing data to third parties without explicit informed consent.

No response-time SLA or supported-version policy is promised at this stage.
